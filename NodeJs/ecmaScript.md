# History and Evolution of JavaScript and ECMAScript

## Origins of JavaScript

- **Created by Brendan Eich** at Netscape in **1995**.
- Developed rapidly in just **10 days**.
- Originally named:
  - **Mocha**
  - Then **LiveScript**
  - Finally **JavaScript**
- Despite its name, **JavaScript has no relation to Java**; the name was chosen for marketing because Java was very popular at the time.
- Designed as a **lightweight scripting language** to add **interactivity to web pages**.
- First appeared in **Netscape Navigator 2.0**.
- Quickly became popular for **client-side programming**, enabling:
  - HTML manipulation
  - Event handling
  - Form validation
  - Dynamic content updates

## The Early Browser War

- **Microsoft launched Internet Explorer**, which included its own variant of JavaScript called **JScript**.
- Different implementations across browsers led to **compatibility issues**.

## The Need for Standardization

- To unify scripting languages and ensure cross-browser compatibility, standardization was necessary.
- In **1996**, Netscape submitted JavaScript to **ECMA International**, an international standards organization.

## ECMAScript Standard

- ECMA created the **ECMAScript** specification to standardize the language.
- JavaScript is an **implementation of ECMAScript**, extended with **browser-specific APIs** like:
  - **DOM (Document Object Model)**
  - **BOM (Browser Object Model)**

## Summary Timeline

| Year | Event                                            |
|-------|------------------------------------------------|
| 1995  | Brendan Eich creates JavaScript at Netscape    |
| 1996  | Netscape submits JavaScript to ECMA International for standardization |
| 1997  | ECMA publishes ECMAScript 1 (ES1) standard     |
| 1990s | Microsoft develops JScript for Internet Explorer |
| 2000s+| ECMAScript evolves with versions like ES3, ES5, ES6 (ES2015), and beyond |

## Key Points

- JavaScript started as a quick, lightweight language for client-side scripting.
- Browser competition led to multiple dialects (JavaScript, JScript).
- Standardization via ECMAScript unified the language specifications.
- Modern JavaScript is ECMAScript plus powerful browser APIs, enabling rich web applications.

### Glossary

| Term          | Meaning                                                       |
|---------------|---------------------------------------------------------------|
| JavaScript    | Programming language created by Netscape, implementation of ECMAScript with browser APIs |
| JScript       | Microsoft's implementation of ECMAScript used in Internet Explorer |
| ECMAScript    | The official standardized specification of the scripting language |
